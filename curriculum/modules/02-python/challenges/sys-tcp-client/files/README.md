# Write a Local TCP Client

**What you will learn:**

- what a socket, an IP address, a port and a TCP connection are
- enough Python to connect, send a line and print the reply

New to this? Read **LESSON.md** first (or press **Lesson** in the app).

## Goal
Complete `client.py`. It must connect only to the local test server. It sends `PING` and prints `PONG`.

## Steps
1. Press Start, then run `./run`.
2. Open the starter and finish the TODO comments.
3. Run `./check` until it passes. Then press Done.

Everything is offline, in one workspace. You need no hardware.
