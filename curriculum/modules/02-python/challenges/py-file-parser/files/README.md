# Parse a Config File

What you will learn:

- how to read a text settings file line by line
- how to skip the lines that do not matter
- how to split "name = value" into two clean pieces
- how to stop with an error (raise ValueError) when a line makes no sense

New to this? Read **LESSON.md** first (or press **Lesson** in the app).

## Goal
Complete parse_config in parse_config.py. The rules are in its docstring (the text under the def line).

## Deliverable
- `python3 parse_config.py receiver.conf` creates `parsed.txt`

## Steps
1. Press Start and read the docstring in parse_config.py.
2. Write parse_config. Run the Deliverable command. Then run `./check`.
3. Press Done when check passes.
