# Talk to a Local Socket

What you will learn:

- what a network socket is
- how a program connects to a server on your own machine (localhost)
- why you must keep reading until the other side has finished

New to this? Read **LESSON.md** first (or press **Lesson** in the app).

## Goal
Complete request_reading in client.py. It must talk to a localhost server.

## Steps
1. Press Start.
2. Try the included server: `./run`
   It should print `channel=7 power=-38`.
3. Prove with a fresh local server: `./check`
4. Press Done when check passes.
