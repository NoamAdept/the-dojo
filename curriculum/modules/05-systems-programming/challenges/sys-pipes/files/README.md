# Connect Parent and Child with a Pipe

**What you will learn:**

- how `fork` makes a second process,
- how to tell the parent and the child apart,
- how a pipe carries bytes from one process to the other.

Are you new to this? Read **LESSON.md** first (or press **Lesson** in the app).

## Goal
Complete `pipe_demo.cpp`. A child process writes `samples=64`. The parent process reads it and prints it.

## Steps
1. Press Start. Then run `./run`.
2. Open `pipe_demo.cpp` and finish the TODO comments.
3. Run `./check` until it passes. Then press Done.

Everything is offline, in one workspace. You need no hardware.
