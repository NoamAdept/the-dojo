# Copy with File Descriptors

**What you will learn:**

- what system calls and file descriptors are,
- how to read command-line arguments in `main`,
- how to copy a file with the low-level POSIX calls `open`, `read`, `write` and `close`.

Are you new to this? Read **LESSON.md** first (or press **Lesson** in the app).

## Goal
Complete `copy.cpp`. Use `open` / `read` / `write` / `close`. Do not use `std::ifstream`.

## Steps
1. Press Start. Then run `./run`. It builds your program and tries your copy.
2. Open `copy.cpp` and finish the TODO comments.
3. Run `./check` until it passes. Then press Done.

Everything is offline, in one workspace. You need no hardware.
