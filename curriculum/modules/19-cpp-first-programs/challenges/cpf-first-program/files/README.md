# Your First C++ Program

**What you will learn:** what a program is, how to write one in C++, and how to change it into a file that you can run.

Is this new for you? Read **LESSON.md** first. Or press **Lesson** in the app.

## Your tasks

1. **Build and run it.** Compile `hello.cpp` into a program called `hello`. Then run it. Do it exactly as LESSON.md shows. You should see `Hello, world!`.
2. **Change the message.** Edit `hello.cpp`. The first line that it prints must be exactly `Hello, C++!`. Keep the `\n`.
3. **Add a second line.** Add a second `std::cout` line below the first one. The program must print exactly:
   ```
   Hello, C++!
   I can compile C++.
   ```
   Then compile again and run `./hello`. You should see both lines. (Task 1 checks that your `hello` program matches your newest `hello.cpp`. So always build again after you edit.)

## Check your work

You can run `./check` as many times as you want. It lists each task that still fails. When it prints `CHECK_OK`, press **Done** in the dojo.
