# Hello, Python

**What you will learn:**

- how to run Python by typing at its prompt
- how to run Python from a `.py` file
- how to print things

New to this? Read **LESSON.md** first (or press **Lesson** in the app).

## Your tasks

Make each file in this folder. Use `vim NAME.py`. Press `i` to type. Press `Esc`, then type `:wq` to save and quit.
Then run the file with `python3 NAME.py` to see what it prints.

1. **Hello**: create `hello.py` so that `python3 hello.py` prints exactly `Hello, Pi!`
2. **Arithmetic**: create `arith.py`. It prints four lines: the results of `7 / 2`, `7 // 2`, `7 % 2` and `2 ** 10`, in that order. Let Python calculate the sums. Write `print(7 / 2)` and so on. Do not write the answers yourself.
3. **Several things in one print**: create `label.py`. It prints exactly `Rate 2048000 Hz`. Use one `print` with three things, separated by commas: the string `"Rate"`, the number `2048000` and the string `"Hz"`.
4. **Read the error**: `broken.py` is already here. It crashes. Run `python3 broken.py`. Read the last line of the error. Fix the file so it prints `Signal found` and then `Done`, on two lines.

## Check your work

Run `./check` as often as you like. It lists every task that still fails. When it prints `CHECK_OK`, press **Done** in the dojo (the course app).
