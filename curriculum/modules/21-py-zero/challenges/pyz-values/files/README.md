# Variables, Types and f-strings

**What you will learn:**

- how to give a value a name
- which kinds (types) of values Python has
- how to put values into text

New to this? Read **LESSON.md** first (or press **Lesson** in the app).

## Your tasks

Open `tasks.py`. Replace each `None` with the right value. Do not change the variable names.

1. **A string**: set `station` to the text `Pi Radio`.
2. **An int**: set `channels` to the whole number `16`.
3. **A float**: set `gain_db` to `20.5`.
4. **A bool**: set `is_on` to `True`.
5. **Conversion**: `text_number` already holds the string `"433"`. Set `as_int` to that text, converted to an int. Use `int(...)` on the variable.
6. **An f-string**: set `label` with an f-string that uses `station` and `channels`. It must read `Pi Radio has 16 channels`.
7. **Number formatting**: `pi` already holds `3.14159`. Set `pi_text` to an f-string. It shows `pi` with two digits after the point. The result is `3.14`.

## Check your work

Run `./check` as often as you like. It lists every task that still fails. When it prints `CHECK_OK`, press **Done** in the dojo.
