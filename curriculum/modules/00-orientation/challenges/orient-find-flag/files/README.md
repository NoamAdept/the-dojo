# Find the Flag

What you will learn:

- how to look around a tree of folders,
- how to see hidden files,
- how to search for files with find,
- how to print a file with cat.

New to this? Read **LESSON.md** first (or press **Lesson** in the app).

## Goal
A secret flag is hidden under labyrinth/. Find it. A flag is text that
starts with the word flag and a curly brace.

## Tools

```
pwd   ls   ls -la   find   cat
```

## Steps
1. Press Start in the dojo. The files appear in this challenge folder.
2. Look around. Run pwd, then ls -la.
3. Explore labyrinth/. Try find. Keep going until you open the file with the flag.
4. Paste that flag in the dojo, or press Done.
