# Your First Commands

**What you will learn:**

- what a terminal, a shell, a prompt and a command are
- how to run your first commands
- how to save what a command prints into a file

New to this? Read **LESSON.md** first. You can also press **Lesson** in the app.

## Your tasks

Type each command in your terminal. Stay in this challenge folder. The terminal opens here.

1. **Your first file**: use `echo` and `>` to make a file `hello.txt`. It must contain exactly `Hello terminal`.
2. **Who are you?**: save the output of `whoami` into a file named `me.txt`.
3. **What time is it?**: save the output of `date` into a file named `today.txt`.
4. **Adding a line**: make a file `list.txt` with 2 lines: `first`, then `second`. Use `>` for the first line. Use `>>` for the second line.

## Check your work

Run `./check` as often as you like. It lists every task that still fails. When it prints `CHECK_OK`, press **Done** in the dojo.
