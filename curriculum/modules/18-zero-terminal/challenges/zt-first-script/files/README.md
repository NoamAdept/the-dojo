# Your First Scripts

**What you will learn:**

- what a script is
- how to write your answers into `answers/taskN.sh` files
- how to test them with `./try N`
- how to grade them with `./check`

All the later shell challenges work this way.

New to this? Read **LESSON.md** first. You can also press **Lesson** in the app.

## Your tasks

Write each answer into its file in `answers/`. Replace the TODO line. Test with `./try N`.

1. **Print a line**: `answers/task1.sh` prints `hello from my script`.
2. **Several lines**: `answers/task2.sh` prints 3 lines: `ready`, then `steady`, then `go`. Use 3 commands on 3 lines.
3. **Make a file**: `answers/task3.sh` creates a file `result.txt` that contains `made by a script`. The file must be in the folder where the script runs.
4. **A folder and a file**: `answers/task4.sh` creates a folder `box`. Inside it, the script creates a file `note.txt` that contains `inside`.

## Check your work

Run `./check` as often as you like. It lists every task that still fails. When it prints `CHECK_OK`, press **Done** in the dojo.
