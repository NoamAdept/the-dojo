# Variables, Quotes and the Practice Dojo

**What you will learn:**

- what a variable is
- why we write `"$DOJO/..."` with double quotes
- how the practice copy works: `dojo/`, `. ./env.sh` and `./try N`

After this, the Linux Shell Basics challenges will feel familiar.

New to this? Read **LESSON.md** first. You can also press **Lesson** in the app.

## Your tasks

Write each answer into its file in `answers/`. Test with `./try N`. Grade with `./check`.

1. **Print a variable**: print the value of `HOME`.
2. **Your own variable**: on the first line, set a variable `band` to `fm`. On the second line, print `listening on fm`. Use `$band` for this. Do not type fm again.
3. **Read from the dojo**: print the contents of `$DOJO/message.txt`. (The check uses a different message than the practice copy.)
4. **Write into the dojo**: create the file `$DOJO/tmp/finished.txt`. It must contain `done`.
5. **A path with a space**: print the contents of `$DOJO/my notes/today.txt`.

## Check your work

Run `./check` as often as you like. It lists every task that still fails. When it prints `CHECK_OK`, press **Done** in the dojo.
