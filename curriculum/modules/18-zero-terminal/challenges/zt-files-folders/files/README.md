# Files and Folders

**What you will learn:**

- what files, folders and paths are
- how to look around with `pwd` and `ls`
- how to move with `cd`
- how to create folders with `mkdir`

New to this? Read **LESSON.md** first. You can also press **Lesson** in the app.

## Your tasks

Start every task from this challenge folder. If you get lost, `cd` back here.

1. **Make a folder**: create a folder named `radio`.
2. **A folder inside a folder**: create a folder `notes` inside `radio`.
3. **Where am I?**: `cd` into `radio/notes`. Then save the output of `pwd` into a file `here.txt`. The file will be in `radio/notes`. Then go back up with `cd ../..`.
4. **List a folder**: save the output of `ls maze` into a file `maze-list.txt`. Put it in this challenge folder.
5. **Find the key**: a file is hidden inside `maze`, 3 folders deep. Its name starts with `key-`. Explore with `cd`, `ls` and `cd ..`. Then go back to the challenge folder. Use `echo` to write that file name into `key.txt`.

## Check your work

Run `./check` as often as you like. It lists every task that still fails. When it prints `CHECK_OK`, press **Done** in the dojo.
