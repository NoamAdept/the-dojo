# Creating and Editing Text Files

**What you will learn:**

- how to create and change text files with the vim editor
- how to save and quit
- how to read files with `cat`

New to this? Read **LESSON.md** first. You can also press **Lesson** in the app.

## Your tasks

1. **A new file with vim**: run `vim shopping.txt` and press `i`. Type 3 lines: `antenna`, `cable`, `battery`. Press `Esc`. Then save and quit with `:wq`.
2. **Fix a typo**: `poem.txt` has a spelling mistake in line 2. `radoi` should be `radio`. Open the file with vim and fix it. Save and quit. Do not change anything else.
3. **Read and answer**: use `cat` to read `message.txt`. Do what it says.
4. **Join two files**: make `both.txt`. Use `cat` with 2 file names and `>`. `both.txt` must hold `shopping.txt` and then `poem.txt`.

## Check your work

Run `./check` as often as you like. It lists every task that still fails. When it prints `CHECK_OK`, press **Done** in the dojo.
