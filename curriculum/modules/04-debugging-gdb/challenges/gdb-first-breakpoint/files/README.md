# First Breakpoint

What you will learn:

- what a debugger is
- how to start GDB
- the 4 commands you will use every time: break, run, print and quit

New to this? Read **LESSON.md** first (or press **Lesson** in the app).

## Goal
Stop at checkpoint in GDB. Read the sample argument.

## Deliverable
- **answer.txt**: only the decimal value of sample

## Steps
1. Press Start, then: `./run`
2. gdb `./target` → break checkpoint → run → print sample
3. Write answer.txt, then: `./check`
4. Press Done when check passes.
