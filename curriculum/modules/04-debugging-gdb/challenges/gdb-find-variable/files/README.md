# Watch a Variable Change

What you will learn:

- how to stop at the same breakpoint again and again with continue
- how to count the stops
- how to read a value at one particular stop

New to this? Read **LESSON.md** first (or press **Lesson** in the app).

## Goal
Break at inspect_here. Continue until the fourth call. Read level.

## Deliverable
- **answer.txt**: level as a decimal integer

## Steps
1. Press Start, then: `./run`
2. GDB: break inspect_here → run → continue (3 more times) → print level
3. Write answer.txt, then: `./check`
4. Press Done when check passes.
