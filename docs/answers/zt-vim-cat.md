# Creating and Editing Text Files

`zt-vim-cat` · White Belt

**Goal:** Use vim to create `shopping.txt`, fix a typo in `poem.txt` and write `code.txt`, then use `cat` to join two files into `both.txt`.

**File `both.txt`**

```text
antenna
cable
battery
Night falls on the hill
The radio hums softly
A signal from far away
Says hello
```

**File `code.txt`**

```text
violet-6666
```

**File `poem.txt`**

```text
Night falls on the hill

Says hello
```

**File `shopping.txt`**

```text

```

Run `./check`. It must print `CHECK_OK`. Then press **Mark as done**.
