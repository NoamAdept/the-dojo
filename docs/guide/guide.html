The Dojo

Learn the terminal, C++ and Python from zero.
Works offline. You only need python3.

1Start

tar -xzf the-dojo.tar.gz
cd the-dojo
./run.sh

Open the address it prints. Press Create account, then Log in.

Windows: double-click The Dojo on the desktop.

2Solve a challenge

  1. Press Read lesson, then Start.
  2. A terminal opens in your folder, ~/dojo/<your name>.
  3. Do the tasks in README.md.
  4. Run ./check. Fix it until it prints CHECK_OK.
  5. Press Mark as done.

3Stuck?

  1. Read the lesson again.
  2. ./check tells you which task is wrong.
  3. Press Hint.

4Belts

Finish one belt to open the next.
